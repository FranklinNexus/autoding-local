# 两日手机定时试用

此版本用于已验华为 JEF-AN00 / API 31 / 1080×2400。它在手机本地设置系统闹钟，保留 PIN 锁；充电不是条件。API 最低版本不代表其他机型已验收。钉钉须保持登录、考勤网络及地点条件正常；手机断电后的运行另行处理。

## 规则与结果

- 只接受最多两个连续日期，使用 Asia/Shanghai。当前试用为 2026-11-18 至 2026-11-19。
- 早上 07:00 打开考勤，优先核验当天已有签到；只有严格识别未打卡及唯一“上班打卡”按钮才提交一次。钉钉自身极速打卡可能在打开时发生，所以导航失败后也不自动重试。
- 下班取 `max(18:30, 当天实际签到 + 9小时 + 10分钟)`。11 月 18 日新截图确认 09:37，因此当晚为 18:47。明日下班根据明日实际回执生成。
- 下班执行前重新读取同日签到；实际签到变晚时最多顺延两次。已满足阈值的下班记录直接确认；异常早退确认页停止，日程任务不继续确认早退。
- 提交点击、成功弹窗与重新进入后读取的实际回执分开记录。过程不明确时停为待核实，不把“打开了 App”当作打卡完成。
- 执行结束尝试重新锁屏。时间超过计划 15 分钟、日期或时区变化、重复/过期任务和持久化失败都会阻止输入。

`NativeTrialScheduler` 使用独立私有偏好设置保存日程、已消费任务、已确认回执与每次结果；替换日程前保留旧日程快照。系统闹钟触发先同步保存 running，再调用原生流程。取消后旧 Intent 不再执行。没有后台无限重试。

重启后首次解锁仍需人工完成。用户解锁后或包更新时只恢复未来未执行任务；中断运行和已过期任务记录状态，不自动补打。用户可在首页关闭定时；诊断页保留“恢复尚未到点的手机任务”入口。

## 安装和配置

按本目录 README 构建并安装同签名研究 APK，保留原 PIN 存储、无障碍和精确闹钟权限，确认厂商允许后台运行。华为需逐个核对研究 App 自己的启动管理：设置 → 应用和服务 → 应用启动管理 → AutoDing 能力研究，关闭自动管理，开启允许自启动、允许关联启动、允许后台活动。原 AutoDing Local 的设置不继承给不同包名的研究 App。先停用原 AutoDing 日常定时及所有电脑输入任务，保存回退状态。两套排程不可同时拥有手机输入。

以下是 DUMP 权限保护的本机 ADB 配置示例；替换 SERIAL、日期和经过官方考勤核实的实际签到。未确认签到时省略最后两个参数，等待早上的真实回执生成下班任务。日期和个人实际时间不硬编码在产品中。

```powershell
adb -s SERIAL shell am broadcast -a org.autoding.research.PROBE `
  -n org.autoding.research/.ProbeBridgeReceiver --es operation schedule-configure `
  --es start_date YYYY-MM-DD --es end_date YYYY-MM-DD `
  --ei morning_minutes 420 --ei floor_minutes 1110 `
  --ei duration_minutes 540 --ei margin_minutes 10 `
  --es verified_date YYYY-MM-DD --es verified_checkin HH:mm
```

读取 `operation=status` 返回的 `nativeSchedule`；核对两个待执行日期及闹钟时间。`schedule-cancel` 先取消日期任务和当前运行；`schedule-restore` 只恢复未来任务。试用结束时状态停用，报告留在手机。研究包未写入原 AutoDing 生产状态。

回退：先停止研究 App 定时，确认其无待执行闹钟；再在原 App 恢复原有设置，最后恢复电脑任务快照。恢复旧任务之前核对当前官方回执，避免因旧状态缺失重复操作。原 PC 解锁路径仍依赖电脑连接，不把它当成手机独立运行。

## 交互首页（2026-11-18）

新版首页提供定时开关、下一次执行时间、试用日期、当天已核实签到与计算出的下班时间、最近结果和运行条件。“设置时间与规则”可调整上班时间、下班最早时间、签到后间隔和额外余量；下班取下班最早时间与实际签到加间隔及余量中的较晚值。保存明确开启日期内安排，取消编辑不改变现有任务。当前仍是最多两天的试用，到期停止。

设置保存保留所选日期内的完整回执、已执行任务和结果历史。已完成、失败、待核实或过期任务保留消费状态，开关或编辑时间不会自动重试。关闭先持久化停用再取消闹钟和运行任务；失败时页面回读真实状态。排程生命周期检查扩展为 47 项，含单次诊断与定时运行的冲突边界。

首页的独立测试统一为只读入口：

1. 保持 USB 连接也可操作，点“准备测试”→“开始 3 分钟倒计时”。
2. 看到“已安排”后拔掉 USB；测试纯电池时不接充电头，按电源键锁屏息屏。
3. 从安排起等满 6 分钟，再接回电脑读取原始报告；也可稍后在首页查看结果。

到点时检查 USB 已断开且锁屏息屏；电池或充电头均接受。首页显示倒计时、电源状态和取消本次测试按钮。与定时任务相距不足 10 分钟时暂缓安排测试，避免争用。只读入口不提交打卡点击，钉钉自身极速打卡仍可能在打开时触发。结束后尝试恢复开始时的锁屏状态。
